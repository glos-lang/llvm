# LLVM
This repository redistributes a minimized LLVM toolchain derived from
[`c3lang/llvm-for-c3`](https://github.com/c3lang/llvm-for-c3) and stripped
further.

LLVM itself is licensed under Apache-2.0 with LLVM Exceptions.

## Removed Components
- Dynamic libraries
- Tools
- LLD libraries
- CMake recipes
- Sanitizer runtime files
